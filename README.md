## 📊 Selected Projects

### 🛒 [Online Retail Analysis](https://github.com/vanitskiy18/online-retail-analysis)

Exploratory analysis of **500,000+ retail transactions** using Python, pandas, NumPy and Matplotlib.

The project covers data cleaning and transformation, revenue and sales dynamics, customer and product analysis, geographic markets, returns, outliers and **time-series patterns**.

**Key skills:** Python · pandas · EDA · Data Visualization · Time Series Analysis

---

### 📈 [Global Market Shock Analysis](https://github.com/vanitskiy18/market-shock-analysis)

Analysis of how major financial markets reacted to global shocks using financial time-series data.

The project includes normalization of asset prices, daily returns, descriptive statistics, correlation analysis and rolling volatility across equities, commodities and FX markets.

**Key skills:** Python · pandas · NumPy · Financial Data Analysis · Time Series

---

### 🤖 [ChatGPT vs Gemini Reviews Analysis](https://github.com/vanitskiy18/chatgpt-vs-gemini-reviews-analysis)

Comparative analysis of approximately **40,000 user reviews** using R and text-mining techniques.

The project includes text preprocessing, NRC sentiment and emotion analysis, word-frequency analysis, word associations using Pearson correlation and Term-Document Matrices, and visualization with ggplot2.

**Key skills:** R · Text Mining · Sentiment Analysis · NLP · Data Visualization

---

### 🌍 [Open Economy Models Simulator](https://github.com/vanitskiy18/macroeconomics-of-the-open-economy-models)

Interactive Python desktop application for exploring macroeconomic models of an open economy.

Users can modify model parameters and observe recalculated outcomes and Matplotlib visualizations in real time. The application includes models of saving and investment, current account, interest rate parity, intertemporal choice and internal/external balance.

**Key skills:** Python · PyQt6 · Matplotlib · Economic Modeling · Interactive Visualization
